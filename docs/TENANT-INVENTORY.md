# Tenant-scope inventory

Generated by `npm run tenant:inventory` (`scripts/tenant-inventory.ts`). Do not edit by hand;
re-run it after changing a model or adding a route.

**What this is.** A static reading of `prisma/schema.prisma` and every `route.ts` under
`src/app/api`. It records which models carry a tenant column, which routes touch them, which
guards a route visibly calls, and whether a tenant filter is visibly present.

**What this is not.** It is not proof that a query is safe. A route can mention
`businessId` and still build the wrong filter, and a guard can be called after a read. This
inventory is the list to review, not the review itself. Behavioural coverage lives in
`tests/tenant-isolation.test.ts`, `tests/organization-isolation.test.ts` and the per-route
suites.
